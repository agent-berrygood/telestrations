# 텔레스트레이션 단어 카드

그림으로 단어를 전달하는 텔레스트레이션 게임용 카드 뽑기 웹앱입니다. 6개 섹션(동물, 음식, 사물과 장소, 속담, 연예인과 스포츠 스타, 캐릭터) × 10개, 총 60개 단어가 들어 있습니다.

- 섹션을 고르거나 **올랜덤**으로 뽑으면 단어 1개가 나오고, 한 번 나온 단어는 다시 나오지 않습니다.
- 단어는 가려진 채로 나오며, 그리는 친구만 탭해서 확인합니다.
- 마지막 뽑기 취소, 나온 단어 보기, 새 게임을 지원하고 진행 상태는 브라우저 localStorage에 저장됩니다.

## 실행

Node.js 22 이상, 외부 패키지 없음.

```sh
npm run dev     # http://127.0.0.1:4173
npm test
npm run build   # dist/ 생성
```

## Vercel 배포

Framework Preset `Other`, Build Command `npm run build`, Output Directory `dist` (`vercel.json`에 설정됨).

## 단어 수정

`public/game.js`의 `SECTIONS`를 고칩니다. 섹션은 6개, 섹션당 단어는 10개, 전체 단어는 중복이 없어야 테스트를 통과합니다. 연예인 섹션은 갤럽코리아 2025 조사 등을 참고한 선정이며 12세 대상 인기도는 확인되지 않았습니다.
